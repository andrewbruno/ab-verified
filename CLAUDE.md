# AB-Verified

## Writing style

- No em dashes. Use commas, colons, parentheses, or split the sentence.
- Australian spelling: colour, organise, centre, licence, recognise.
  Code identifiers and CSS properties keep their required US spelling
  (`color`, `text-align: center`).

## Commits

- Succinct messages. One clear subject line is usually enough.
- Add a body only when the reason is not obvious from the diff.
- No `Co-Authored-By` trailer, no session links, no generated-with footer.

## Layout

- `docs/SPEC.md` is the marketplace specification. `docs/README.md` indexes the documentation.
- `docs/palette/` holds the design tokens (colours, fonts, type scale) taken
  from forward-deployed-engineer.ai. Read it before building any UI.
- `docs/wireframes/` holds the wireframes.
